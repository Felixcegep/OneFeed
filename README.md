# OneFeed

OneFeed is a reader for the iPhone and the Mac. It keeps a short daily list, a queue for later, and your sources in folders.

- Today is a small stack from the sources you leave on.
- Queue is where a story waits.
- Feed is your folders. Open a folder, or New articles, to read from a source.
- The same link or the same YouTube video is one article.
- Outlets covering the same event stay together. You see the newest source, then “N more sources about this story.”
- Today keeps one slot for that event. The other sources stay in Feed.
- If you already read a match, the row says so.
- A related topic stays a normal row.
- French and English are not compared with each other.
- Finish a story with Done, Queue, or Skip. Done can keep a short note.
- Subscriptions and reading state can live in a library file on iCloud Drive or Google Drive.
- Videos can be understood further with Gemini only if you turn on “Tell similar videos apart” in Settings. The feed does not wait for that.

Open `OneFeed.xcodeproj` in Xcode 27 or later.
